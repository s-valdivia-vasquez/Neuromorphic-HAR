# UCI HAR Dataset

The UCI HAR dataset is not included in this repository.

Download the original dataset from:

```text
https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones
```

Place and extract the files in this directory:

```text
data/UCI HAR Dataset/
```

Expected structure:

```text
data/UCI HAR Dataset/
├── train/
├── test/
├── activity_labels.txt
├── features.txt
├── features_info.txt
├── README.txt
└── README.md
```
