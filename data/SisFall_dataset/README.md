# SisFall Dataset

The SisFall dataset is not included in this repository.

Download the original dataset from:

```text
https://www.kaggle.com/datasets/nvnikhil0001/sis-fall-original-dataset
```

Place and extract the files in this directory:

```text
data/SisFall_dataset/
```

Expected structure:

```text
data/SisFall_dataset/
├── SA01/
├── SA02/
├── ...
├── SE01/
├── ...
└── README.md
```
